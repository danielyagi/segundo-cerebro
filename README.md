# 🧠 Segundo Cérebro

Repositório de conhecimento organizado por categorias, mantido pelo Hermes Agent.

## Estrutura

```
segundo-cerebro/
├── perito/          # Conhecimento de perícia judicial
│   ├── tjsp/        # Tribunal de Justiça de São Paulo
│   └── tjpr/        # Tribunal de Justiça do Paraná (Projudi)
├── dev/             # Desenvolvimento de software
├── financas/        # Finanças pessoais / empresariais
├── saudebemestar/   # Saúde e bem-estar
├── produtividade/   # Ferramentas e métodos de produtividade
└── aprendizado/     # Estudos e aprendizados diversos
```

## Rotina

- **Diário às 20h**: salvamento automático de conhecimento novo
- O agente analisa o uso do dia, token count e custo
- Só salva se houve conteúdo relevante no dia
- Novas pastas só criadas com aprovação do usuário
