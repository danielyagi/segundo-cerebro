# Bolsas 100% Integrais para Medicina no Exterior

**Data:** 13/08/2026
**Contexto:** Pesquisa para enteada em 9º ano do ensino fundamental, desejo de cursar medicina no exterior sem condições financeiras para custear.

## Conclusão Principal

**Única opção viável de bolsa 100% integral em medicina: Coreia do Sul via GKS (Global Korea Scholarship / KGSP).**

## Coreia do Sul — GKS/KGSP

| Característica | Detalhe |
|---|---|
| Cobertura | ✅ 100% — passagem aérea, matrícula, estadia mensal, seguro médico, treinamento de coreano |
| Nível | Undergraduate (pós-ensino médio) |
| Medicina | ✅ Disponível em SNU, Yonsei, Korea University, Catholic University, etc. |
| Idade limite | < 25 anos (realista do 9º ano → aplicar aos 17-18) |
| GPA mínimo | 80%+ no último ciclo educacional |
| Coreano | TOPIK não obrigatório upfront — treinamento incluso |
| Inscrições | Ago-Set (Embassy Track), Set-Out (University Track) |
| Vagas | ~500 undergrads/ano |

### Universidades participantes com medicina
- Seoul National University (SNU)
- Yonsei University
- Korea University
- Catholic University of Korea
- Ajou University
- Gachon University
- Jeju National University

## EUA — Backup (pré-med apenas)

- **Harvard/Amherst/Williams:** 100% need-based se renda < US$ 65k/ano, mas **não oferecem medicina** — apenas pré-med (Biology, Biochemistry)
- **JWU Global Full Tuition:** 100% tuition, mas estadia não inclusa (~US$ 15-20k/ano)
- **QuestBridge:** aplicação para baixa renda (setembro)

## Outros Países — Sem Cobertura Integral

Canadá (Vanier/NSERC = apenas PhD), Alemanha (DAAD = parcial), Reino Unido (Chevening = Master's), Austrália/NZ (bolsas parciais), Fulbright Brasil (Master's/PhD).

## Plano Recomendado

1. **Fase 1 (agora-3 anos):** Completar ensino médio, GPA > 8.0, TOEFL 100+ ou IELTS 7.0, coreano básico (TOPIK 3), voluntariado em saúde
2. **Fase 2 (final ensino médio):** Aplicar GKS Embassy Track + universidades coreanas; EUA como backup via QuestBridge
